# ⚡ AuthMatrix Project Rules & Guidelines

## 🛡️ Supply Chain Security & Dependency Policy (Mandatory)

* **Minimum 7-Day Package Age Requirement:** Before installing, upgrading, or adding any `npm` package or third-party library, verify that the specific version being requested has a **minimum release age of at least 7 days** from its publish date on the registry.
* **Prohibition on Brand-New Releases:** Do NOT install package versions that were released within the last 7 days.
* **Rationale:** Protects the codebase and system from supply chain attacks, maintainer account takeovers, and malicious zero-day version releases.
